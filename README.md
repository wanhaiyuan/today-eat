# 今天吃啥 · 湘信周边抽签器

湖南信息职业技术学院望城校区（旺旺中路 8 号）周边餐馆网页，手机可用，访客无须登录。

网站：https://wanhaiyuan.github.io/today-eat/

## 2026 年资料核对（尚未完整）

查询于 2026-10-03。原来 18 条 2022–2023 年的历史记录已撤出抽签池，不能把无新证据的店一律当作已停业。

- 可抽名单目前只有 1 家：柳州老牌螺蛳粉（信息学院店）。百度地图详情页显示 2026-09-17、2026-08-18 的用餐评价。评价不保证今天仍营业。
- 6 家候选在本次百度地图周边搜索中出现，但尚无今年的营业证据；候选不参与抽签。
- 逐店查询持续超时，尚未完成周边全部门店及旧店停业情况的核对。

查询日期 checkedAt 与评价日期 reviewDate 分开保存，不能将查询日期伪装成商家资料更新时间。

## 范围与来源

在百度地图选择地址为旺旺中路 8 号的学校地点，点击“附近”搜索“美食”，读取结果显示的距离并筛选不超过 1,000 米的门店。本版不再使用城市吧历史坐标自行计算距离；百度学校定位与原坐标存在口径差异，页面明确标为“地图周边距离”。距离不代表从宿舍出发的步行路线。

周边结果来源：https://j.map.baidu.com/t/M1Ffrv

具体门店详情链接见 data.js。未编造营业时间、菜单、价格或评分。综合美食广场、纯饮品店、茶楼、小酒馆、校内食堂不进入签池。地图记录可能滞后，新店或流动摊位可能遗漏。

restaurants.csv 只导出可抽名单；candidates.csv 单独导出待核实名单。页面保留资料入口和高德导航搜索链接。

## 发布与使用

纯 HTML、CSS、JavaScript，无须安装依赖或配置数据库。GitHub Pages 使用 main 分支根目录部署，index.html 位于仓库根目录。

有多家通过核对后，抽签每轮不重复；目前只有 1 家，再抽仍会是同一家，页面会明确提示。
