# 今天吃啥 · 湘信周边抽签器

湖南信息职业技术学院望城校区（旺旺中路 8 号）周边餐馆抽签网页，适配手机。

- 随机抽一家，一轮内不重复。
- 收录 18 家公开地图位置直线距离不超过 1 公里的餐馆和小吃店。
- 查看地址、资料来源，打开高德地图搜索。
- 纯 HTML、CSS 和 JavaScript，无须安装依赖或配置数据库。

## 发布到 GitHub Pages

1. 新建公开仓库，例如 today-eat。
2. 将本目录里的文件直接上传到仓库根目录，确保 index.html 在根目录。
3. 打开仓库 Settings → Pages。
4. Build and deployment 的 Source 选择 Deploy from a branch。
5. Branch 选择 main，目录选择 / (root)，点击 Save。
6. 等待部署成功，在 Pages 页面点击 Visit site。

项目网站地址通常为 https://wanhaiyuan.github.io/today-eat/ 。以 Pages 页面显示的地址为准。

## 使用与资料范围

网站访客无须登录 GitHub。国内访问质量需要用实际手机网络验证。

以城市吧学校地图位置（BD-09：112.823848,28.347241）为中心，使用同来源同坐标系计算球面直线距离。直线距离不等于步行距离。资料整理于 2026-10-03，多数店铺记录来自 2022–2023 年；可能有遗漏或停业，出发前请打开地图确认。页面逐项保留资料日期和来源。

restaurants.csv 为完整收录清单。图片为 Wikimedia Commons 的公有领域牛肉面照片，非收录店铺实拍，页面保留出处链接。
